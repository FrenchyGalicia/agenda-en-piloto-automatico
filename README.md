# Agenda en piloto automático
**Cómo diseñar sistemas de citas que no dependan de la memoria**

## Introducción
Muchos negocios con agenda tienen el mismo problema: cancelaciones, olvidos y seguimiento irregular.  
El error habitual es pensar que se soluciona cambiando de herramienta, cuando en realidad casi siempre es un problema de **sistema**, no de software.

Este repositorio describe el **enfoque mínimo necesario** para que una agenda funcione de forma estable antes de automatizar nada.

## El problema real
Una agenda falla cuando depende de la memoria, cuando no hay un flujo claro **antes, durante y después** de la cita, y cuando cada caso se gestiona “como siempre”.

En ese contexto, la tecnología no ordena: **amplifica el caos**.

## El sistema básico

**Antes de la cita**
- Confirmaciones claras  
- Recordatorios con sentido (no genéricos)

**Durante la cita**
- Registro correcto de lo ocurrido  
- Decisión explícita sobre los próximos pasos

**Después de la cita**
- Seguimiento si hay continuidad  
- Cierre del ciclo si no la hay

## El error más común
Automatizar sin haber definido el sistema.  
Las herramientas solo ejecutan lo que ya está definido, **bien o mal**.

Primero se diseña el sistema.  
Después se automatiza.

## Para quién es
Clínicas y negocios de servicios con agenda que quieren reducir fricción y errores operativos.

No depende de un software concreto.  
Depende de **criterio operativo**.

## Nota final
Una agenda en piloto automático no elimina el trato humano.  
Elimina la fricción, los olvidos y la improvisación constante.

Y eso, a medio plazo, es lo que sostiene cualquier negocio con citas.
